# 基于安路 FPGA 的实时图像处理与视觉辅助抓取系统

基于安路（Anlogic）HX1P35A 开发平台（PH1P35MDG324）实现的实时数字图像处理系统，扩展了目标检测与视觉引导机械臂的完整闭环演示。系统通过 MIPI 摄像头采集视频，在 FPGA 上完成多模式图像处理与红/蓝/绿三色目标检测，再通过串口将三色坐标下发至 STM32 驱动的机械臂，实现自动抓取分拣。

> 本项目为「全国大学生嵌入式芯片与系统设计竞赛」参赛作品（选题二：基于安路 FPGA 的实时数字图像处理系统）。

## 系统组成

| 部分 | 内容 |
|------|------|
| FPGA 平台 | 安路 HX1P35A 开发板（PH1P35MDG324，速度等级 -3） |
| 图像采集 | SC500CS MIPI 2-Lane 摄像头 |
| 图像输出 | HDMI 1280×720@60fps |
| 图像处理 | 直通、灰度、二值化、反色、伽马、边缘检测、卡通化、三色识别共 8 种模式 |
| 检测算法 | HSV 色彩空间判色 + 连通域跟踪（时分复用，帧 N 红 / N+1 蓝 / N+2 绿） |
| 机械臂 | 六舵机机械臂（5 用 1 备），STM32F103C8 独立控制 |
| 通信 | UART 115200，逐条应答（红→蓝→绿，每条等 done） |

## 关键设计

### 图像处理流水线

```
MIPI 采集 → RAW10 解包 → ISP(去马赛克/白平衡) → DDR2 帧缓存 → 8 种处理模式 → HDMI 输出 + OSD
```

- **边缘检测**：3×3 Sobel，`|Gx|+|Gy|` 免开方，自适应阈值（整帧平均梯度 × 系数）。
- **二值化**：16×16 因果滑动窗口局部均值门限，移位替代除法。
- **伽马校正**：gamma 2.2 八段折线近似，暗部提亮、亮部平缓，50% 混合兼顾对比度。
- **三色检测**：HSV 判色（除法折叠为交叉相乘比较，无除法器、不占 DSP），时分复用单套连通域跟踪硬件。

### 视觉引导机械臂闭环

```
三色检测 → coord_batch 打包坐标 → UART → STM32 解析 → 逆运动学解算 → 舵机抓取分拣
```

- FPGA 侧 `coord_batch` 将质心换算为「屏幕底边中点为原点」的像素坐标。
- STM32 侧 `PixelToArm` 结合标定参数（BOTTOM_EDGE_MM、CAM_X_MM、CAM_Y_MM）换算为机械臂毫米坐标。
- 三关节逆运动学解算（末端姿态角固定），定步长线性插值平滑运动。

## 按键说明

| 按键 | 功能 |
|------|------|
| KEY1 | 切换 8 种图像处理模式 |
| KEY2 / KEY3 | 调节亮度 / 对比度 |
| KEY4 | 触发三色坐标经串口发送（STM32 收到坐标后才驱动机械臂） |

## 编译与烧录

### FPGA（安路 TangDynasty）

1. 用安路 TD 软件打开工程（工程文件见 `td_project`，或新建工程并导入 `fpga/rtl` 源码）。
2. **注意**：MIPI 物理层、DDR 控制器、HDMI 收发、PLL、FIFO 等 IP 核由 TD 软件生成（涉及加密/版权，本仓库不含），需在 TD 中重新生成/导入后综合。
3. 综合、布局布线后生成 bit 流烧录。

### STM32（Keil MDK）

1. 用 Keil MDK 打开 `stm32/project.uvprojx`。
2. 编译后烧录至 STM32F103C8。
